# PlantBuddy Documentation

This folder is the project handoff pack for PlantBuddy. It explains the current codebase as it exists now, not only the original idea.

## Recommended Reading Order

1. [Project Plan](project-plan.md) - product direction, MVP scope, and build phases.
2. [Current Implementation](current-implementation.md) - what is actually built right now.
3. [Setup And Run](setup-and-run.md) - how to install dependencies, configure Supabase, and run the app.
4. [Architecture And File Structure](architecture-and-file-structure.md) - where things live and how the pieces connect.
5. [Database And Supabase](database-and-supabase.md) - database schema, RLS, and Supabase setup notes.
6. [Todo Roadmap](todo-roadmap.md) - prioritized unfinished work.
7. [AI Opportunities](ai-opportunities.md) - realistic ideas for future AI matching, search, profile help, chats, and mini games.
8. [Security And Vulnerabilities](security-and-vulnerabilities.md) - current risks and fixes to prioritize.
9. [Risk And Best Practices Guide](risk-and-best-practices-guide.md) - current/future security and functionality risks plus development practices.
10. [Testing And Quality Plan](testing-and-quality-plan.md) - recommended verification strategy.
11. [Developer Handoff Report](developer-handoff-report.md) - concise contributor handoff summary.
